## 📋 Officiel & Réglementaire

- [autoentrepreneur.urssaf.fr](https://autoentrepreneur.urssaf.fr) — Portail officiel URSSAF : déclarations de chiffre d'affaires, simulation de cotisations, gestion du compte.
- [impots.gouv.fr](https://www.impots.gouv.fr) — Déclaration fiscale, versement libératoire de l'impôt sur le revenu, franchise en base de TVA.
- [guichet-entreprises.fr](https://www.guichet-entreprises.fr) — Création, modification et cessation d'activité en ligne (remplace le CFE depuis 2023).
- [legifrance.gouv.fr](https://www.legifrance.gouv.fr) — Textes de loi : régime micro-entrepreneur, CFE, cotisations, TVA, seuils.
- [service-public.fr — Micro-entrepreneur](https://www.service-public.fr/professionnels-entreprises/vosdroits/F23267) — Fiche officielle complète sur le régime.
- [chorus-pro.gouv.fr](https://chorus-pro.gouv.fr) — Portail de facturation électronique obligatoire pour les entités publiques (B2G).

## 🧮 Simulateurs & Outils de calcul

- [Eikio](https://eikio.fr) — Application dédiée aux auto-entrepreneurs : facturation, simulation des cotisations URSSAF, suivi du chiffre d'affaires et gestion administrative simplifiée.
- [mon-entreprise.urssaf.fr](https://mon-entreprise.urssaf.fr) — Simulateur officiel URSSAF : cotisations sociales, revenus nets, comparatif statuts.
- [Simulateurs fiscaux impots.gouv.fr](https://www.impots.gouv.fr/simulateurs) — Simulateurs officiels : impôt sur le revenu, versement libératoire, TVA.
- [Microcitron](https://microcitron.fr) — Guides pratiques et calculateurs pour micro-entrepreneurs : seuils, cotisations, déclarations.

## 🧾 Facturation & Comptabilité

- [Eikio — Facturation](https://eikio.fr) — Création de devis et factures conformes, export PDF, suivi des paiements, génération Factur-X.
- [Factur-X / ZUGFeRD — FNFE](https://www.fnfe-mpe.org/factur-x/) — Standard européen de facturation électronique hybride (PDF/A-3 + XML CII). Format retenu pour la réforme française.
- [Présentation Factur-X officielle (PDF)](https://www.fnfe-mpe.org/wp-content/uploads/2021/05/FNFE-MPE-Factur-X-presentation-20210518.pdf) — Documentation technique du standard.

## ⚡ Réforme e-Facturation 2027

La réforme de la facturation électronique obligatoire en France impose, à partir de **2027**, l'émission et la réception de factures électroniques pour toutes les entreprises assujetties à la TVA.

- [dgfip.finances.gouv.fr — e-facturation](https://www.impots.gouv.fr/professionnels/la-facturation-electronique-entre-assujettis-tva) — Page officielle DGFiP sur la réforme, le calendrier et les obligations.
- [fnfe-mpe.org](https://www.fnfe-mpe.org) — Forum National de la Facture Électronique : actualités, groupes de travail, documentation technique.
- [Iopole](https://iopole.fr) — Plateforme de Dématérialisation Partenaire (PDP) agréée DGFiP, compatible Factur-X.
- [Chorus Pro](https://chorus-pro.gouv.fr) — PDP publique, déjà obligatoire pour le B2G, modèle de ce que sera le B2B.

**Format obligatoire :** Factur-X (FR) / ZUGFeRD (DE/EU) — PDF/A-3 embarquant un fichier XML CII.

## 🏛️ Protection sociale & Retraite

- [ameli.fr](https://www.ameli.fr) — Assurance maladie : droits, remboursements et indemnités journalières en tant qu'indépendant.
- [retraite.gouv.fr](https://www.retraite.gouv.fr) — Estimation de retraite, trimestres validés, rachat de trimestres.
- [cipav.fr](https://www.cipav.fr) — Caisse de retraite des professions libérales (hors URSSAF).
- [secu-independants.fr](https://www.secu-independants.fr) — Sécurité sociale des indépendants, rattachée au régime général depuis 2020.

## 💰 Fiscalité

- [Versement libératoire de l'IR](https://www.impots.gouv.fr/professionnel/le-versement-liberal-de-limpot-sur-le-revenu) — Option permettant de payer l'impôt sur le revenu en même temps que les cotisations URSSAF.
- [CFE — Cotisation Foncière des Entreprises](https://www.impots.gouv.fr/professionnel/la-cotisation-fonciere-des-entreprises-cfe) — Taxe locale due par tous les auto-entrepreneurs (exonération la 1ère année).
- [ACRE — Aide aux Créateurs](https://www.urssaf.fr/accueil/services-en-ligne/acre.html) — Exonération partielle de cotisations sociales la 1ère année.

## 📦 Librairies & Outils Dev

Pour les développeurs qui intègrent le régime auto-entrepreneur dans leurs applications.

- [horstoeko/zugferd](https://github.com/horstoeko/zugferd) — PHP — Génération et lecture de factures Factur-X / ZUGFeRD. Utilisé pour la conformité à la réforme e-facturation.

## Contribuer

Les contributions sont les bienvenues ! Pour ajouter une ressource :

1. Fork ce dépôt
2. Ajoute ta ressource dans la catégorie appropriée, en respectant le format existant
3. Vérifie que le lien est fonctionnel et que la ressource est pertinente pour les auto-entrepreneurs français
4. Ouvre une Pull Request avec une courte description

**Critères d'inclusion :**
- Ressource en français ou directement utile au marché français
- Lien fonctionnel et contenu à jour
- Pas de contenu promotionnel pur sans valeur informative

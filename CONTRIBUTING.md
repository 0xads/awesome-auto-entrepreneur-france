# Contributing

Merci de contribuer à `awesome-auto-entrepreneur-france`.

L'objectif du dépôt est de référencer des ressources réellement utiles aux auto-entrepreneurs et micro-entrepreneurs en France, avec une priorité donnée aux sources officielles, pérennes et pratiques.

## Ce que nous acceptons

- Ressources officielles françaises : administration, organismes publics, portails réglementaires, caisses, annuaires publics.
- Guides de référence utiles au marché français.
- Outils ou services réellement pertinents pour la gestion d'une micro-entreprise.
- Librairies open source liées à la facturation, Factur-X, UBL, conformité, calculs ou automatisation.
- Communautés actives et modérées apportant une vraie valeur d'entraide.

## Ce que nous évitons

- Pages purement marketing sans contenu utile.
- Articles dupliquant une information officielle sans apport réel.
- Ressources obsolètes, non maintenues ou liens cassés.
- Affiliation masquée, spam SEO, pages générées automatiquement.
- Outils non pertinents pour un public basé en France.

## Format attendu

Chaque entrée doit respecter ce format :

```md
- [Nom](https://example.com) — Description courte et concrète.
```

Règles de style :

- Une seule ressource par ligne.
- Nom clair, idéalement le nom officiel du site, produit ou projet.
- Description courte, factuelle et utile.
- Pas de superlatifs marketing.
- Préférer le français quand c'est possible.
- Préférer `https`.

## Où ajouter une ressource

- Placez la ressource dans la catégorie la plus pertinente.
- Si aucune catégorie n'est adaptée et qu'il y a au moins 4 ou 5 ressources comparables, vous pouvez proposer une nouvelle section.
- Évitez les doublons entre catégories.

## Priorités éditoriales

En cas d'arbitrage, l'ordre de priorité est :

1. Source officielle
2. Source durable et maintenue
3. Utilité pratique immédiate
4. Clarté pour un micro-entrepreneur en France

## Vérifications avant PR

- Le lien fonctionne.
- La ressource est toujours accessible sans parcours bloquant.
- La catégorie est la bonne.
- La description est neutre.
- Il n'existe pas déjà une entrée équivalente.
- Le Markdown reste propre et homogène.

## Pull requests

Les PRs petites et ciblées sont préférées.

Merci d'inclure :

- ce que vous ajoutez, modifiez ou supprimez ;
- pourquoi la ressource mérite d'être listée ;
- toute information utile sur l'obsolescence ou la mise à jour d'un lien existant.

## Nettoyage et maintenance

Les mainteneurs peuvent :

- reformuler une description pour homogénéiser le style ;
- déplacer une ressource dans une autre catégorie ;
- refuser une ressource trop promotionnelle ou insuffisamment fiable ;
- supprimer des liens devenus obsolètes.

## Idées de contributions utiles

- Ajouter des ressources officielles manquantes.
- Remplacer des liens datés par leur version actuelle.
- Compléter les sections TVA, e-facturation et protection sociale.
- Ajouter des projets open source liés à Factur-X ou à l'automatisation administrative.
